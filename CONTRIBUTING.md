# Contributing to VCstack

Thank you for your interest in contributing to VCstack!

VCstack is an open-source venture intelligence toolkit designed to support startup research, investment analysis and portfolio monitoring through AI-powered research skills.

## How to contribute

You can contribute by:

- Improving existing research skills.
- Adding new VC research workflows.
- Improving research accuracy and source verification.
- Fixing bugs and documentation issues.
- Suggesting new features.
- Improving workflow orchestration.

## Getting started

1. Fork the VCstack repository.
2. Clone your fork locally.
3. Create a new branch for your changes.
4. Make your changes.
5. Test your changes before submitting.
6. Submit a pull request with a clear description.

## Contribution guidelines

- Keep contributions focused and understandable.
- Follow the existing SKILL.md structure when adding skills.
- Avoid fabricated research or unsupported investment claims.
- Include credible sources when introducing factual research.
- Do not commit API keys, credentials or personal information.
- Update documentation when introducing new functionality.

## Pull requests

Every pull request should explain:

- What was changed?
- Why was it changed?
- Which files were affected?
- How was the change tested?

## Reporting issues

Use GitHub Issues to report bugs, suggest improvements or request new features.

All contributors are expected to follow the project's Code of Conduct.

Thank you for helping improve VCstack!
